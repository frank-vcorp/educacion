## 6. RIESGOS / DESVIACIONES

### 6.1 Generación PDF no produce binario (decisión MVP)

**Severidad:** L2 (cosmético — HTML imprimible funciona, no es PDF nativo).
**Impacto:** El director abre el endpoint y el navegador imprime a PDF (cmd+P).
**Mitigación futura:** Activar `PDF_GENERATOR=playwright` + `@sparticuz/chromium` cuando Frank apruebe deploy (50MB extra de bundle, cold start +5s).

### 6.2 Wizard paso 7 (Sesiones) sin bloques arrastrables

**Severidad:** L2 (funcional — la planeación se guarda sin sesiones).
**Impacto:** La maestra debe volver a editar para agregar bloques del catálogo M1.
**Mitigación:** Sesión 4 con `@dnd-kit/sortable` agregará la vista `/planeaciones/[id]/editar` con drag-drop completo.

### 6.3 F-IA1 determinista vs LLM (no usa MiniMax)

**Severidad:** L1 (no impacto funcional — calidad de sugerencia es razonable para keywords explícitos).
**Impacto:** Sugerencias menos matizadas que un LLM pero sin coste/latencia/audit trail débil.
**Mitigación:** El módulo está aislado en `services/recursos-aula/sugerir-uso.ts` — cuando Frank active LLM se reemplaza la función interna manteniendo la firma.

### 6.4 RLS cross-tenant test (T-E2E-07) NO ejecutado

**Severidad:** **BLOQUEANTE para promoción a producción**.
**Impacto:** Sin Supabase corriendo, no podemos validar que maestra CCT-A NO lee planeaciones CCT-B.
**Estado:** Test stub creado en `tests/integration/rls-cross-tenant.test.ts`, se auto-skipea si `SUPABASE_TEST_URL` no está definida.
**Acción Frank:** Levantar `supabase start` local + ejecutar `pnpm test:integration` antes de promover a staging.

### 6.5 Tests E2E Playwright (T-E2E-01..05) no escritos
