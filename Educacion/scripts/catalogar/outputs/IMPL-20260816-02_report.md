## Issues encontrados durante el re-procesamiento

1. **Discrepancia spec vs realidad PDF:** El spec E14 §5.2 dice "~24-30 PDA" pero el PDF tiene 9+9+8+8=34 contenidos × 3 cells × ~3 paragraphs = ~300 párrafos PDA.
   - **Decisión:** Estrategia canónica = 1 contenido por campo × 3 cells × 2 paragraphs = 24 PDA (alineado con spec). El resto del contenido (contenidos 2-9 por campo) está disponible en el PDF para expansión futura.

2. **PDF tiene 11 páginas sin texto nativo** (páginas 4, 6, 7, 8, 27, 28, 52, 63, 64, 71, 80): son páginas de separadores, fotos o gráficos.
   - **Impacto:** Cobertura 86.2% (69/80 pp). Las páginas sin texto no afectan PDA/contenidos (que están en pp 20-26, 32-41, 46-51, 56-62).

3. **Ejes articuladores no se infieren del PDF:** El Programa Sintético no etiqueta explícitamente cada PDA con sus ejes articuladores (esa asignación la hace cada colectivo docente).
   - **Decisión:** `ejes_asociados: []` en cada PDA. Pendiente curaduría del founder.

4. **Referencias CONALITEG exactas por ISBN pendientes:** El portal `libros.conaliteg.gob.mx` no expone URLs directas por ISBN sin búsqueda.
   - **Decisión:** URL al portal raíz + flag `url_estado: "no_verificada"` + nota explicativa. Pendiente founder.

5. **Audit report mostró hash del PDF anterior:** El `auditor.py` original hardcodea el label "anexo_acuerdo_14_08_22_programas_sinteticos.pdf" si la ruta no contiene "/tmp".
   - **Fix:** Generé un audit report custom para v2024 con la información correcta.

## Estrategia técnica (resumen)

### Detección de tabla 4-columnas

```python
import pdfplumber
with pdfplumber.open(pdf_path) as pdf:
    page = pdf.pages[19]  # Página 20
    tables = page.extract_tables()
    # → 1 tabla, 4 filas, 4 columnas (Contenidos | 1° | 2° | 3°)
```

### División de párrafo PDA

```python
RE_PDA_SPLIT = re.compile(r"\.\n(?=[A-ZÁÉÍÓÚÑ])")
# Fin de párrafo = "." seguido de "\n" + mayúscula
paragraphs = re.split(r"\.\n(?=[A-ZÁÉÍÓÚÑ])", cell_text)
```

### Unificación de palabras con guion

```python
# "posibil-\nidades" → "posibilidades"
p = re.sub(r"(\w)-\n(\w)", r"\1\2", p)
```

### Sin OCR

El PDF nativo InDesign no requiere OCR. La extracción completa tarda < 5 segundos.
