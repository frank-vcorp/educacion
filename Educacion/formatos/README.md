## Resumen de Estructura

### Campos Obligatorios (según SEP)

1. **Datos generales**: Escuela + CCT, docente, grado/grupo, ciclo, periodo, fechas, # sesiones
2. **Elementos curriculares**:
   - Campos formativos (4 opciones)
   - Contenidos
   - PDA
   - Ejes articuladores
   - Problema del contexto
3. **Secuencia didáctica**: Inicio, Desarrollo, Cierre (con tiempos)
4. **Evaluación formativa**: Instrumentos, evidencias, indicadores

### Diferencias NEM vs Modelo Anterior

| Aspecto | 2011 | NEM |
|---------|------|-----|
| Tiempo por planeación | Semanal | 2-6 semanas (proyectos) |
| Punto de partida | Contenido | Problema del contexto |
| Evaluación | Sumativa | Formativa |
| Organización | Asignaturas | Campos formativos |
